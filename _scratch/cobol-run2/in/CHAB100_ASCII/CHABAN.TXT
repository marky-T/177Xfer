       PROCEDURE DIVISION.  
       P0.  
           OPEN INPUT CAR OUTPUT FIC.   
       STATIS.  
           DISPLAY 'STATISTIQUES DE CREATION' UPON PRINTER. 
           DISPLAY 'NOMBRE DE CARTES DONNEES LUES' UPON PRINTER.
           ADD CTFS CTCAR GIVING CTTEST.
           DISPLAY CTTEST UPON PRINTER. 
           DISPLAY 'NOMBRE DE CARTES DONNEES POUR FS' CTFS  
                                        UPON PRINTER.   
           DISPLAY 'NOMBRE DE CARTES DONNEES CREATION' CTCAR
                                        UPON PRINTER.   
           DISPLAY 'NOMBRE DE RECORDS CREES' CTOUT  UPON PRINTER.   
           IF CTSPEC = CTTEST   
                    DISPLAY 'FIN DU TRAVAIL,TOUT EST OK' UPON PRINTER   
           ELSE DISPLAY 'VERIFIER OUTPUT' 'IL Y AVAIT TROP PEU DE CARTES
      -      ' DONNEES OU FS' UPON PRINTER. 
       FIN. 
           CLOSE FIC CAR.   
           STOP RUN.
       ECRIOUT. 
           WRITE ZFIC FROM ZOUT.
           ADD 1 TO CTOUT.  
       FIECRIOUT.   
           EXIT.
       PARAG.   
           MOVE ZCEM (IED) TO ZTR (IRD).
           ADD 1 TO IED IRD.
           IF IED NOT > IEF GO TO PARAG.
       FIPARAG. 
           EXIT.
       RECHA.   
           MOVE 0 TO IED.   
       INC1.
           ADD 1 TO IED.
           IF ZONE = ALPHA (IED) GO TO CONT1.   
           IF IED < 26 GO TO INC1.  
           GO TO RECHN. 
       CONT1.   
           SUBTRACT IED FROM VINSIX GIVING ZREP.
           IF ZREP NOT < VALEUR ADD VALEUR TO IED   
                                MOVE ALPHA (IED) TO ZONE
                                MOVE SPACE TO RETOUR
                                GO TO FIRECHA.  
           SUBTRACT ZREP FROM VALEUR GIVING IED.
           MOVE ALPHA (IED) TO ZONE.
           MOVE 'R' TO RETOUR.  
           MOVE 1 TO VALEUR.
           GO TO FIRECHA.   
       RECHN.   
           MOVE 0 TO IED.   
       INC2.
           ADD 1 TO IED.
           IF ZONE = NUMER (IED) GO TO CONT2.   
           IF IED < 10 GO TO INC2.  
           MOVE '*' TO ZONE.
           MOVE SPACE TO RETOUR.
           GO TO FIRECHA.   
       CONT2.   
           SUBTRACT IED FROM DIX GIVING ZREP.   
           IF ZREP NOT < VALEUR ADD VALEUR TO IED   
                                MOVE NUMER (IED) TO ZONE
                                MOVE SPACE TO RETOUR
.                               GO TO FIRECHA.  
           SUBTRACT ZREP FROM VALEUR GIVING IED.
           MOVE NUMER (IED) TO ZONE.
           MOVE 'R' TO RETOUR.  
           MOVE 1 TO VALEUR.
           GO TO FIRECHA.   
       FIRECHA. 
           EXIT.
