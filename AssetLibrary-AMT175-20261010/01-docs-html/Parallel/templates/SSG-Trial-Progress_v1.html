Pipeline steps:
  1. Edit programs.manifest.json — set paramOverrides / conditionValues / status
  2. Run Convert-SsgToLion.ps1 → inspect candidate, fix overrides, re-run until 0 converter errors
  3. Create fixtures/<key>/ — hand-derive input.dat + expected.dat
  4. Write tools/refimpl/<key>.ps1 — Tier-1 reference oracle
  5. Run Run-EclProof.ps1 -Program <KEY> → Column A = ✓ PASS when diff=0
  6. (Deferred) Import .LionSource into AMT Dev Studio → build → run → Column B = PASS
