*DEFINE FILUN   
*SET FILLUN  TO  [#1]-1 
*END
*DEFINE FILDEU  
*SET FILLDEU TO  [#1]-[#2]-[#3]+1   
*END
@UCOB,I   TPF$.NAME$,TPF$.MONTANT   
       IDENTIFICATION DIVISION. 
       PROGRAM-ID. MONTANT. 
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.   
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT  FILEIN  ASSIGN TO DISC [INPUT,1,1,1].
           SELECT  FILEOUT ASSIGN TO DISC [OUTPUT,1,1,1].   
       DATA DIVISION.   
       FILE SECTION.
       FD  FILEIN   
           LABEL RECORD IS STANDARD 
           BLOCK CONTAINS [INPUT,1,1,3]  RECORDS
           RECORD CONTAINS [INPUT,1,1,2]  CHARACTERS
           DATA RECORD IS REC-IN.   
       01  REC-IN             PIC X([INPUT,1,1,2]). 
       FD  FILEOUT  
           LABEL RECORD IS STANDARD 
           BLOCK CONTAINS [OUTPUT,1,1,3]  RECORDS   
           RECORD CONTAINS [OUTPUT,1,1,2]  CHARACTERS   
           DATA RECORD IS REC-OUT.  
       01  REC-OUT            PIC X([OUTPUT,1,1,2]).
       WORKING-STORAGE SECTION. 
       01  WS-IN  PIC X([INPUT,1,1,2]). 
*INCREMENT I FROM 1 BY 1 TO [MONTANT]   
       01  WS-IN[*I] REDEFINES WS-IN.   
*PROCESS FILUN [MONTANT,I,1,1]  
               03 FILLER    PIC X([*FILLUN]).   
               03 MONTANT[*I]  PIC S9([MONTANT,I,1,2]). 
*PROCESS FILDEU [INPUT,1,1,2] [MONTANT,I,1,1] [MONTANT,I,1,2]   
               03 FILLER    PIC X([*FILLDEU]).  
*LOOP   
       01  WS-OUT  PIC X([OUTPUT,1,1,2]).   
*INCREMENT I FROM 1 BY 1 TO [MONTANT]   
       01  WS-OUT[*I] REDEFINES WS-OUT. 
*PROCESS FILUN [MONTANT,I,1,1]  
               03 FILLER    PIC X([*FILLUN]).   
               03 MONTANT[*I]  PIC S9([MONTANT,I,1,2]). 
*PROCESS FILDEU [OUTPUT,1,1,2] [MONTANT,I,1,1] [MONTANT,I,1,2]  
               03 FILLER    PIC X([*FILLDEU]).  
*LOOP   
       PROCEDURE DIVISION.  
       DEBUT.   
           OPEN INPUT FILEIN
                OUTPUT FILEOUT. 
       LECTURE. 
           READ FILEIN INTO WS-IN AT END GO TO FIN. 
           MOVE WS-IN TO WS-OUT.
*INCREMENT I FROM 1 BY 1 TO [MONTANT]   
           COMPUTE MONTANT[*I] OF WS-OUT[*I] = MONTANT[*I] OF WS-IN[*I] * +1

*LOOP   
           WRITE REC-OUT FROM WS-OUT.   
           GO TO LECTURE.   
       FIN. 
           CLOSE FILEIN FILEOUT.
           STOP RUN.
