       IDENTIFICATION DIVISION.     
       PROGRAM-ID.  SORT-FICHOUT-1.  
       ENVIRONMENT DIVISION.  
       CONFIGURATION SECTION. 
       SOURCE-COMPUTER. UNIVAC-1106.
       OBJECT-COMPUTER. UNIVAC-1106.
       INPUT-OUTPUT SECTION.  
       FILE-CONTROL.    
           SELECT  TAPE-1  ASSIGN
                                        DISC FICHIN-1. 
           SELECT  TAPEOUT  ASSIGN  
                              DISC FICHOUT-1.    
           SELECT SORTFILE ASSIGN TO MASS-STORAGE XA. 
       DATA DIVISION.   
       FILE SECTION.    
       FD  TAPE-1    
           LABEL RECORD STANDARD    
                   BLOCK CONTAINS 1 RECORDS     
                   DATA RECORD IS REC-IN-1.  
       01  REC-IN-1            PIC X(80).     
       FD  TAPEOUT  LABEL RECORD IS STANDARD    
                    RECORD CONTAINS 80 CHARACTERS     
                    DATA RECORD IS REC-OUT.     
       01  REC-OUT           PIC X(80).   
       SD  SORTFILE     
                    DATA RECORD IS SORT-REC.    
       01  SORT-REC   PIC  X(80).   
       01  SORT-R1.
           03  SORT-KEY-1     PIC X(8).   
       WORKING-STORAGE SECTION.     
       01  INPUT-CT-MESS-1.
           03  FILLER         PIC X(24)   
                    VALUE  'INPUT RECORD COUNT FROM '.
           03  FILLER         PIC X(12)   
                    VALUE  'FICHIN-1'.     
           03  INPUT-CT-1  PIC Z(11)9. 
       01  IN-CT-1         PIC  9(10)  COMP    VALUE ZERO.     
       01  OUTPUT-CT-MESS.    
           03  FILLER         PIC X(24)   
                    VALUE  'OUTPUT RECORD COUNT TO  '.
           03  FILLER         PIC X(12)   
                    VALUE  'FICHOUT-1 '.   
           03  OUTPUT-CT      PIC  Z(11)9.
       01  OUT-CT             PIC  9(10)   COMP   VALUE ZERO.     
       PROCEDURE DIVISION.    
       SORT-START SECTION.    
       SORTING.   
           OPEN INPUT  TAPE-1.   
           OPEN OUTPUT TAPEOUT.     
           SORT SORTFILE ON ASCENDING KEY 
                          SORT-KEY-1  
                              INPUT PROCEDURE  IS INP 
                              OUTPUT PROCEDURE IS OUTP.     
           GO  TO  CLOSE-FILES.     
       INP SECTION.     
       INPUT-PROC-1. 
           READ   TAPE-1   INTO  SORT-REC    
                    AT END GO TO  CLOSE-1.   
           ADD  1   TO  IN-CT-1. 
           RELEASE  SORT-REC.                GO TO INPUT-PROC-1.     
       CLOSE-1.   CLOSE  TAPE-1.    
       INP-EXIT.    EXIT.     
       OUTP SECTION.    
       OUTPUT-PROC.     
           RETURN SORTFILE              AT END GO TO OUTP-EXIT.   
           ADD  1  TO  OUT-CT.
           WRITE  REC-OUT  FROM SORT-REC.         GO TO OUTPUT-PROC.    
       OUTP-EXIT.   EXIT.     
       CLOSE-FILES  SECTION.  
       ENDING-RUN.
           MOVE  IN-CT-1   TO  INPUT-CT-1.
           DISPLAY  INPUT-CT-MESS-1  UPON PRINTER. 
           MOVE  OUT-CT  TO  OUTPUT-CT.   
           DISPLAY  OUTPUT-CT-MESS  UPON  PRINTER.    
           CLOSE TAPEOUT.     
           STOP RUN.
