

       IDENTIFICATION DIVISION.     
       PROGRAM-ID. UNLOAD-ASCII.    
       AUTHOR. BOURDEAUD HUY 13/05/82.    
       ENVIRONMENT DIVISION.  
       CONFIGURATION SECTION. 
       SOURCE-COMPUTER. UNIVAC-1100-60EIS.
       OBJECT-COMPUTER. UNIVAC-1100-60EIS.
       INPUT-OUTPUT SECTION.  
       FILE-CONTROL.    
           SELECT BDE  ASSIGN  TO   
               DISC "ECL-TAPEOUT".  *> SSG-STUB [OUTPUT,1,1,1]
           SELECT DISQ ASSIGN  TO  DISC  ECL-TAPEIN  *> SSG-STUB [INPUT,1,1,1]
           RESERVE 20 AREAS   
              ORGANIZATION IS INDEXED     
              ACCESS MODE IS SEQUENTIAL RECORD KEY IS  CLEF 
           ALTERNATE RECORD KEY IS CLEG.  
       DATA DIVISION.   
       FILE SECTION.    
       FD  BDE  BLOCK CONTAINS 1 RECORDS  *> SSG-STUB [OUTPUT,1,1,3]
               RECORD CONTAINS 80 CHARACTERS  *> SSG-STUB [OUTPUT,1,1,2]
                LABEL RECORD IS STANDARD  
                DATA RECORD IS  ZBDE.     
       01  ZBDE    PIC  X(80).  *> SSG-STUB [OUTPUT,1,1,2]
0     
       FD  DISQ   LABEL RECORD IS STANDARD
           BLOCK CONTAINS 1 RECORDS  *> SSG-STUB [INPUT,1,1,3]
               RECORD CONTAINS 80 CHARACTERS  *> SSG-STUB [INPUT,1,1,2]
                  DATA RECORD  IS ZDISQ.  
       01  ZDISQ. 
       WORKING-STORAGE SECTION.     
       77  CTR     PIC  9(10)  COMP  VALUE  0.  
       77  REP     PIC  X.    
       77  MAXBDE  PIC  9(10)   COMP  VALUE   99999999.     
       01  MES1.  
           02 FILLER  PIC X(19) VALUE 'NB.ARTICLES ECRITS='.
           02 CTR-1   PIC 9(7).     
       01  ZBUF.  
              06 FILLER  PIC  X(80).  *> SSG-STUB [INPUT,1,1,2]
       01  ZBUF1      REDEFINES  ZBUF.    
       PROCEDURE DIVISION.    
       DEB. 
           OPEN OUTPUT  BDE.  
           OPEN  INPUT   DISQ.
           MOVE SPACES TO ZBUF.     
           MOVE ALL ' ' TO CLEF.    
       DEBF.
           READ DISQ INTO ZBUF AT END GO TO FBDE.     
           ADD  1  TO  CTR.   
           WRITE  ZBDE  FROM ZBUF.  
           MOVE SPACES TO ZBUF.     
           MOVE  CTR  TO  CTR-1.    
           GO TO DEBF.  
       CLOS.
           CLOSE  BDE.  
           CLOSE  DISQ. 
           STOP  RUN.   
       FBDE.
           DISPLAY  'FIN DE FICHIER' UPON  CONSOLE.   
           MOVE   CTR   TO CTR-1.   
           DISPLAY  MES1   UPON  CONSOLE. 
           GO TO  CLOS.
