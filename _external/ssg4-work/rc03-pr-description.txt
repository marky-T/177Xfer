## What this is
Release candidate rc.03 of the generic SSG utility programs for application BSP.
Ten precompiled generic COBOL programs replace the per-call SSG-generated programs for eleven
OS 2200 SSG utilities (CFH-COPY and LOADIS share one program). Each converted runstream still calls
its skeleton; a hand-off at the top of the skeleton writes the call's SGS cards to a parameter file
and runs the generic program instead.

Work item: #119872

## Contents
- BSP_AMT\Development\Programs\<Project>: 10 C# projects generated by LionDev 177 from LionSource
  GNBSP4, in solution folder /Programs/ of _All_.slnx. All build with 0 errors.
- Scripts\ASSURFED_UTILIT: the hand-off skeletons and their includes (replace R&D's converted
  skeletons of the same names).
- Scripts\Settings\AmtSettings.xml: CloneReports entries (Xqt name -> generic program).
- Utilities\: README, RELEASE-NOTES (changes since rc.02, CC proof, known issues), INSTALL,
  PROGRAM-SUMMARY, manifest.csv (every file of the release with its SHA256), Reference\Cobol (the 10
  COBOL sources the programs were generated from).
- Scripts_SSG\ removed (the withdrawn rc.01 PowerShell bodies).

Programs: CFH_COPY_GN, BABA_GN, FUSBA_GN, CHABAN_GN, CONDIS2_GN, SCAN_GN, TAPELD_GN,
LECTIS_GN, ARCHISEPARE_GN, ARCHIFORMAT_GN (298 real calls).

## Proof
Control Center regression in the trial application, 12 Nov 2026: 18 of 18 jobs PASS.
Outputs compared byte for byte with independent reference results; error cases end in Error before
the program starts. Table in Utilities\RELEASE-NOTES.md.
