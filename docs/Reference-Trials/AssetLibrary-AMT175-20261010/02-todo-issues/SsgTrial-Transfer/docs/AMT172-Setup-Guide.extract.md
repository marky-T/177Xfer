### Bare-IF fix (new pattern — Bug 17a)

      When `[COND,1,I,1]` resolves to empty string (COND,1=0), the COBOL fragment `IF / NEXT SENTENCE / ELSE GO TO FIN.` is syntactically invalid — ERR 000084. Since the whole block is a no-op at COND,1=0, delete all 3 lines. Do not add a macro stub; the empty result is correct. Record in `cobol-convert-pipeline.md`.
