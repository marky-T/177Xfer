# SSG-4 Control Center Runbook — run record archive

Older run records moved out of the **Run record** tab of
[SSG4-ControlCenter-Runbook.html](SSG4-ControlCenter-Runbook.html). The tab keeps three: *Last*, *Previous*,
*To be archived*. When a new run is recorded, the *To be archived* record is converted to Markdown and added
**at the top** of this file (newest first), then the tab shifts by one.

Each entry keeps: date and window, what ran (Ids, programs), summary outcome, results table, problems met,
and where the evidence is (`_scratch\cc-runs\<program>`, `AmtTools\Basepaths\Logs\<yyyyMMdd>\`).
