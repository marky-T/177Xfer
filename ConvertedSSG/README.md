converted to **PowerShell** by the `SsgConverter`, for transfer to and execution on the **AMT172**
working environment against the real AMT PowerShell runtime (`AmtPsEclLib`).

Each `.ps1` begins with a `# Converted from SSG source: <name>` header and was generated by
`SsgConverterConsole`. All 10 reach **0 PowerShell parse errors** and were exercised in the Tier-1
mock harness before bundling.

The exact 10 SSG source files given to `SsgConverter` as input to produce the `.ps1` files above

## Running on AMT172

These scripts call into the AMT PowerShell runtime (e.g. `GetSgsValue`, `DataLineOrNoStatement`,
`CompareTypeSafe`, `Process-Skip`, `Call-ExternalProgram`). On AMT172 they must run with the real
`AmtPsEclLib` module loaded and the application initialised — not the Tier-1 mock. Each accepts an
optional `-Parameters` string array:

```powershell
.\CFH-COPY.ps1 -Parameters @(...)
```

## Tier1Mock/ — our verified mock harness (for when `AmtPsEclLib` isn't available)

If the real `AmtPsEclLib` runtime isn't installed on the target box, `Tier1Mock/` is our own
mock-shell used to validate every program in this bundle before pushing (0 parse errors + expected
output on all 10):

- `SsgPsMockLib.psm1` — implements only the primitives the generated scripts call: `GetSgsValue`,
  `DataLineOrNoStatement`, `CompareTypeSafe`, `Process-Skip`, `Call-ExternalProgram`, `Fin`, `Abort`,
  `AddTo-SgsList`, `RemoveFrom-SgsList`, `Sort-SgsList`.
- `Run-SsgPsTrial.ps1` — seeds the mock SGS table from a per-program `sgs-values/<Program>.sgs-values.json`,
  runs the script, captures every emitted line.
- `sgs-values/<Program>.sgs-values.json` — the parameter values we seeded for each of the 10 programs.

Usage:

```powershell
Import-Module .\Tier1Mock\SsgPsMockLib.psm1 -Force -DisableNameChecking
.\Tier1Mock\Run-SsgPsTrial.ps1 -Program CFH-COPY `
  -ScriptPath .\CFH-COPY.ps1 -ValuesFile .\Tier1Mock\sgs-values\CFH-COPY.sgs-values.json
```

**Important lesson worth reconciling with any independently-built mock** (e.g. `Mock-SsgRuntime.psm1`):
`GetSgsValue` must return **typed** values (`[Int64]`/`[Double]`), not raw strings. A string-only mock
causes two silent bugs: (1) `+` becomes string concatenation instead of arithmetic in `*SET` chains,
and (2) the string `"0"` is truthy in PowerShell (only `""` is falsy) while the int `0` is falsy, so a
disabled feature (e.g. `MAXCOPY=0`) wrongly evaluates as enabled in bare `If ((GetSgsValue (...)))`
checks. See `SsgPsMockLib.psm1`'s `GetSgsValue` for the coercion logic.
