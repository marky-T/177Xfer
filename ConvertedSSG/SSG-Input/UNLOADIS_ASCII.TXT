       IDENTIFICATION DIVISION. 
       PROGRAM-ID. UNLOAD-ASCII.
       AUTHOR. BOURDEAUD HUY 13/05/82.  
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.   
       SOURCE-COMPUTER. UNIVAC-1100-60EIS.  
       OBJECT-COMPUTER. UNIVAC-1100-60EIS.  
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT BDE  ASSIGN  TO   
*IF [OUTPUT,1,1] > 3
               INTERCHANGE [OUTPUT,1,1,1].  
*ELSE   
               DISC [OUTPUT,1,1,1]. 
*END
           SELECT DISQ ASSIGN  TO  DISC  [INPUT,1,1,1]  
              ORGANIZATION IS INDEXED   
               RESERVE 5 AREAS  
              ACCESS MODE IS SEQUENTIAL RECORD KEY IS  CLEF.
       DATA DIVISION.   
       FILE SECTION.
       FD  BDE  BLOCK CONTAINS [OUTPUT,1,1,3] RECORDS   
               RECORD CONTAINS [OUTPUT,1,1,2] CHARACTERS
*IF [OMITTED] > 0   
                LABEL RECORD IS OMITTED 
*ELSE   
                LABEL RECORD IS STANDARD
*END
                DATA RECORD IS  ZBDE.   
       01  ZBDE    PIC  X([OUTPUT,1,1,2]).  
       FD  DISQ   LABEL RECORD IS STANDARD  
           BLOCK CONTAINS [INPUT,1,1,3] RECORDS 
               RECORD CONTAINS [INPUT,1,1,2] CHARACTERS 
                  DATA RECORD  IS ZDISQ.
       01  ZDISQ.   
*IF [KEYIS,1,1,1] = 0   
           02 CLEF PIC X([KEYIS,1,1,2]).
           02 FILLER PIC X([KEYIS,1,1,3]).  
*ELSE   
           02 FILLER PIC X([KEYIS,1,1,1]).  
           02 CLEF PIC X([KEYIS,1,1,2]).
           02 FILLER PIC X([KEYIS,1,1,3]).  
*END
       WORKING-STORAGE SECTION. 
       77  CTR     PIC  9(10)  COMP  VALUE  0.  
       77  REP     PIC  X.  
*IF   [MAXREC]  >  0
       77  MAXBDE  PIC  9(10)  COMP  VALUE  [MAXREC,1,1,1]. 
*ELSE   
       77  MAXBDE  PIC  9(10)   COMP  VALUE   99999999. 
*END
       01  MES1.
           02 FILLER  PIC X(19) VALUE 'NB.ARTICLES ECRITS='.
           02 CTR-1   PIC 9(7). 
       01  ZBUF.
              06 FILLER  PIC  X([INPUT,1,1,2]). 
       01  ZBUF1      REDEFINES  ZBUF.  
*IF [KEYIS,1,1,1] = 0   
               02 RKEY1 PIC X([KEYIS,1,1,2]).   
               02 FILLER PIC X([KEYIS,1,1,3]).  
*ELSE   
               02 FILLER PIC X([KEYIS,1,1,1]).  
               02 RKEY1 PIC X([KEYIS,1,1,2]).   
               02 FILLER PIC X([KEYIS,1,1,3]).  
*END
       PROCEDURE DIVISION.  
       DEB. 
           OPEN OUTPUT  BDE.
           OPEN  INPUT   DISQ.  
           MOVE LOW-VALUES    TO CLEF.  
       DEBF.
           READ DISQ INTO ZBUF AT END GO TO FBDE.   
           ADD  1  TO  CTR. 
           WRITE  ZBDE  FROM ZBUF.  
           MOVE  CTR  TO  CTR-1.
           GO TO DEBF.  
       CLOS.
           CLOSE  BDE.  
           CLOSE  DISQ. 
           STOP  RUN.   
       FBDE.
           DISPLAY  'FIN DE FICHIER' UPON  CONSOLE. 
           MOVE   CTR   TO CTR-1.   
           DISPLAY  MES1   UPON  CONSOLE.   
           GO TO  CLOS.
