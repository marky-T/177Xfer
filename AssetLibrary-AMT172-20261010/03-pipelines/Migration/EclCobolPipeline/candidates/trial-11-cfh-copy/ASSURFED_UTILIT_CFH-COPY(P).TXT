    
       IDENTIFICATION DIVISION. 
       PROGRAM-ID. 'CFH-COPY'.  
       AUTHOR. MICHEL REVISED BY BOURDEAUD HUY. 
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.   
       SOURCE-COMPUTER. UNIVAC-1106.
       OBJECT-COMPUTER. UNIVAC-1106.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT  TAPEIN  ASSIGN  TO  UNISERVO ECL-TAPEIN.  *> SSG-STUB [INPUT,1,1,1]
           SELECT  TAPEOUT  ASSIGN  TO  MASS-STORAGE ECL-TAPEOUT.  *> SSG-STUB [OUTPUT,1,1,1]
       DATA DIVISION.   
       FILE SECTION.
       FD  TAPEIN   
           LABEL  RECORD  STANDARD  
           BLOCK CONTAINS 1  RECORDS  *> SSG-STUB [INPUT,1,1,3]
           DATA RECORD RECIN.   
       01  RECIN   PIC  X(80).  *> SSG-STUB [INPUT,1,1,2]
       FD  TAPEOUT  
           LABEL  RECORD STANDARD   
           BLOCK  CONTAINS 1  RECORDS  *> SSG-STUB [OUTPUT,1,1,3]
           DATA RECORD RECOUT.  
       01  RECOUT   PIC   X(80).  *> SSG-STUB [OUTPUT,1,1,2]
       WORKING-STORAGE SECTION. 
       77  NB-LUS   PIC   9(10)  COMP  VALUE 0. 
       01   SWITCHES.   
           03  REC-SKIPPED  PIC  S9(6) VALUE ZEROES.
       PROCEDURE DIVISION.  
       DEBUT.   
           OPEN INPUT TAPEIN.   
           OPEN  OUTPUT  TAPEOUT.   
       LECT.
           MOVE SPACES TO RECOUT.   
           READ  TAPEIN  AT  END  GO TO  FINW.  
           MOVE RECIN TO RECOUT.
           ADD 1  TO NB-LUS.
           WRITE RECOUT.
           GO TO LECT.  
       FINW.
           DISPLAY  '*CFH-COPY  FIN*'  UPON  PRINTER.   
           DISPLAY  '*NB-ENREG-LUS ='  NB-LUS  UPON  PRINTER.   
           CLOSE  TAPEIN.   
           CLOSE  TAPEOUT.  
           DISPLAY  REC-SKIPPED  UPON  PRINTER. 
           STOP RUN.
