
       IDENTIFICATION DIVISION.     
       PROGRAM-ID. LOADIS-ASCII.    
       AUTHOR. BOURDEAUD HUY 13/05/82.    
       ENVIRONMENT DIVISION.  
       CONFIGURATION SECTION. 
       SOURCE-COMPUTER. UNIVAC-1100-60EIS.
       OBJECT-COMPUTER. UNIVAC-1100-60EIS.
       INPUT-OUTPUT SECTION.  
       FILE-CONTROL.    
           SELECT  BDE1  ASSIGN TO      *> SSG-STUB
               DISC FICHIN-1.   *> SSG-STUB
           SELECT DISQ ASSIGN TO DISC  FILEOUT-1  *> SSG-STUB
           RESERVE 20 AREAS   
           ORGANIZATION IS INDEXED  
            ACCESS  MODE IS DYNAMIC RECORD KEY IS CLEF
           ALTERNATE RECORD KEY IS CLEG.  
       DATA DIVISION.   
       FILE SECTION.    
       FD  BDE1 *> SSG-STUB
           LABEL RECORD STANDARD    
             BLOCK CONTAINS 1   RECORDS    *> SSG-STUB
           RECORD CONTAINS 120 CHARACTERS    *> SSG-STUB
           DATA RECORD IS  Z1.    *> SSG-STUB
       01  Z1   PIC  X(120).  *> SSG-STUB
       FD  DISQ   LABEL RECORD STANDARD   
           BLOCK CONTAINS 1 RECORDS *> SSG-STUB
           RECORD  CONTAINS 80 CHARACTERS  *> SSG-STUB
             DATA RECORD IS ZDISQ CLEFA.  
       01  ZDISQ  PIC  X(80).  *> SSG-STUB
       01  CLEFA. 
           02 CLEF PIC X(1).   *> SSG-STUB
           02 CLEG PIC X(1).   *> SSG-STUB
           02 CLEH PIC X(1).   *> SSG-STUB
       WORKING-STORAGE SECTION.     
       77  FF  PIC  9(10)  COMP  VALUE 1. 
       77  CTRIN  PIC  9(10)  COMP  VALUE  0.   
       01  WREC.  
           02 FILLER  PIC  X(80).    *> SSG-STUB
       01  WREC1     REDEFINES  WREC.     
           02 KEYA PIC X(1).   *> SSG-STUB
           02 KEYB PIC X(1).   *> SSG-STUB
           02 KEYC PIC X(1).   *> SSG-STUB
       PROCEDURE DIVISION.    
       DEBUT.     
           OPEN INPUT  BDE1.      *> SSG-STUB
           OPEN  OUTPUT  DISQ.
       LECT.
           GO TO LECT1 FINB  DEPENDING  ON FF.  
       LECT1.     
           MOVE SPACES TO Z1.     *> SSG-STUB
           READ  BDE1  INTO  WREC  AT END ADD 1 TO FF  GO TO LECT.
           GO TO CONT.  
       CONT.
           MOVE KEYA     TO  CLEF.  
           MOVE KEYB     TO  CLEG.  
           MOVE KEYC     TO  CLEH.  
           ADD  1  TO  CTRIN. 
           WRITE ZDISQ FROM WREC INVALID KEY GO TO  ERRDISQ.
           MOVE SPACES TO WREC WREC1 ZDISQ.     
           GO TO LECT.  
       FINB.
           DISPLAY 'NB.RECORDS ECRITS'  CTRIN  UPON PRINTER.
           CLOSE  DISQ. 
           CLOSE  BDE1.     *> SSG-STUB
           STOP RUN.    
       ERRDISQ.   
           DISPLAY 'IS.ERROR'  CLEF  UPON  PRINTER.   
           ENTER ASM 'ABORT'.
