    
       IDENTIFICATION DIVISION. 
       PROGRAM-ID. 'CFH-COPY'.  
       AUTHOR. MICHEL.  
       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.   
       SOURCE-COMPUTER. UNIVAC-1106.
       OBJECT-COMPUTER. UNIVAC-1106.
       SPECIAL-NAMES.   
           DECIMAL-POINT IS COMMA.  
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT  TAPEIN  ASSIGN  TO  DISC FILEIN-1.  *> SSG-STUB [INPUT,1,1,1]
           SELECT  TAPEOUT  ASSIGN  TO  DISC FILEOUT-1.  *> SSG-STUB [OUTPUT,1,1,1]
       DATA DIVISION.   
       FILE SECTION.
       FD  TAPEIN   
           LABEL  RECORD  STANDARD  
           BLOCK CONTAINS 1  RECORDS  *> SSG-STUB [INPUT,1,1,3]
           DATA RECORD RECIN.   
       01  RECIN   PIC  X(80).  *> SSG-STUB [INPUT,1,1,2]
       FD  TAPEOUT  
           LABEL  RECORD STANDARD   
           BLOCK  CONTAINS 1  RECORDS  *> SSG-STUB [OUTPUT,1,1,3]
           DATA RECORD RECOUT.  
       01  RECOUT   PIC   X(80).  *> SSG-STUB [OUTPUT,1,1,2]
       WORKING-STORAGE SECTION. 
       77  NB-LUS   PIC  S9(10)  COMP  VALUE 0. 
       77  LNCTR  PIC  S9(2)  VALUE 58. 
       01  COPY-LIMIT         PIC 9(10) VALUE 1.  *> SSG-STUB [MAXCOPY,1,1,1]
       01   SWITCHES.   
           03  REC-SKIPPED  PIC  S9(6) VALUE ZEROES.
       PROCEDURE DIVISION.  
       DEBUT.   
           OPEN INPUT TAPEIN.   
           OPEN  OUTPUT  TAPEOUT.   
       LECT.
           MOVE SPACES TO RECOUT.   
           READ  TAPEIN  AT  END  GO TO  FINW.  
           MOVE RECIN TO RECOUT.
           ADD 1  TO NB-LUS.
           ADD 1  TO LNCTR. 
           WRITE RECOUT AFTER 2.
           IF  NB-LUS  NOT <  COPY-LIMIT  GO TO FINW.   
           GO TO LECT.  
       FINW.
           DISPLAY  '*CFH-COPY  FIN*'  UPON  PRINTER.   
           DISPLAY  '*NB-ENREG-LUS ='  NB-LUS  UPON  PRINTER.   
           CLOSE  TAPEIN.   
           CLOSE  TAPEOUT.  
           DISPLAY  REC-SKIPPED  UPON  PRINTER. 
           STOP RUN.
