       PROCEDURE DIVISION.  
       OUVERT.  
           OPEN OUTPUT IMP. 
           WRITE ZPRINT FROM ZP1 BEFORE PAGE.   
           OPEN INPUT FICHIN.   
                    MOVE LOW-VALUES TO SYMK.
           START  FICHIN KEY IS GREATER THAN SYMK INVALID KEY   
           GO TO LECTURE.   
           GO TO LECTURE.   
                    MOVE LOW-VALUES TO SYMK1.   
           START  FICHIN KEY IS GREATER THAN SYMK1 INVALID KEY  
           GO TO LECTURE.   
           GO TO LECTURE.   
                    MOVE LOW-VALUES TO SYMK2.   
           START  FICHIN KEY IS GREATER THAN SYMK2 INVALID KEY  
           GO TO LECTURE.   
           GO TO LECTURE.   
       LECTURE. 
           READ FICHIN NEXT RECORD INTO WREC AT END GO TO FIN.  
           ADD 1 TO CTR.
           GO TO LECTURE.   
              IF
           1  *> SSG-STUB
                    NEXT SENTENCE   
                                      ELSE GO TO FIN.   
       SUITE.   
           MOVE CTR TO FILCO.   
           WRITE ZPRINT FROM TIT BEFORE 1.  
           MOVE WREC TO ZPR.
           PERFORM IMPRES THRU FIIMPRES.
           GO TO LECTURE.   
           OPEN INPUT FICHIN.   
           OPEN INPUT CARTE.
       LOOP.
           READ CARTE AT END GO TO FIN. 
           MOVE ZL1 TO SYMK INDICATIF2. 
           PERFORM FORMAT-CLE THRU FORMAT-CLE-EXIT  
           MOVE    TAB-OUTPUT TO SYMK  INDICATIF2   
      *    display 'symk  = ' symk upon printer.
           START FICHIN KEY = SYMK INVALID KEY ADD 1 TO CTR 
           GO TO ERREUR.
           MOVE ZL1 TO SYMK1 INDICATIF2.
           PERFORM FORMAT-CLE THRU FORMAT-CLE-EXIT  
           MOVE    TAB-OUTPUT TO SYMK1 INDICATIF2   
      *    display 'symk1 = ' symk1 upon printer.   
           START FICHIN KEY = SYMK1 INVALID KEY ADD 1 TO CTR
           GO TO ERREUR.
           MOVE ZL1 TO SYMK2 INDICATIF2.
           PERFORM FORMAT-CLE THRU FORMAT-CLE-EXIT  
           MOVE    TAB-OUTPUT TO SYMK2 INDICATIF2   
      *    display 'symk2 = ' symk2 upon printer.   
           START FICHIN KEY = SYMK2 INVALID KEY ADD 1 TO CTR
           GO TO ERREUR.
       LECTURE-RANDOM.  
           READ FICHIN NEXT INTO WREC AT END
           GO TO ERREUR.
           IF SYMK = INDICATIF2 
           MOVE WREC TO ZPR PERFORM IMPRES THRU FIIMPRES
           GO TO LECTURE-RANDOM.
           GO TO ERREUR.
           READ FICHIN NEXT INTO WREC AT END
           GO TO ERREUR.
           IF SYMK1 = INDICATIF2
           MOVE WREC TO ZPR PERFORM IMPRES THRU FIIMPRES
           GO TO LECTURE-RANDOM.
           GO TO ERREUR.
           READ FICHIN NEXT INTO WREC AT END
           GO TO ERREUR.
           IF SYMK2 = INDICATIF2
           MOVE WREC TO ZPR PERFORM IMPRES THRU FIIMPRES
           GO TO LECTURE-RANDOM.
           GO TO ERREUR.
       ERREUR.  
           GO TO LOOP.  
       FIN. 
           MOVE SPACES TO ZPRINT.   
           WRITE ZPRINT BEFORE SAUT.
           DISPLAY '** FIN DU TRAVAIL **' UPON PRINTER. 
EXIT
           DISPLAY 'NOMBRE DE RECORDS LUS ** ' CTR UPON PRINTER.

           CLOSE CARTE. 
           STOP RUN.

       FORMAT-CLE.  
           MOVE SPACES   TO TAB-OUTPUT. 
           MOVE ZL1      TO TAB-INPUT.  
           MOVE 1        TO INDEXI INDEXO.  
           PERFORM MOVE-CHAR THRU MOVE-CHAR-EXIT SW-AVANT TIMES.
           IF TAB-I (INDEXI) NOT = '2'  
              ADD 2 TO INDEXI   
              PERFORM MOVE-CHAR THRU MOVE-CHAR-EXIT 2 TIMES 
           ELSE 
              ADD 1 TO INDEXI   
              IF  TAB-I (INDEXI)     = '0' AND  
                  TAB-I (INDEXI + 1) = '0'  
                  MOVE ';' TO TAB-O (INDEXO)
                  ADD  2   TO INDEXI
                  ADD  1   TO INDEXO
                  PERFORM MOVE-CHAR THRU MOVE-CHAR-EXIT 
              ELSE  
              IF  TAB-I (INDEXI)     = '0' AND  
                  TAB-I (INDEXI + 1) = '1'  
                  MOVE '_' TO TAB-O (INDEXO)
                  ADD  2   TO INDEXI
                  ADD  1   TO INDEXO
                  PERFORM MOVE-CHAR THRU MOVE-CHAR-EXIT 
              ELSE  
              IF  TAB-I (INDEXI)     = '0' AND  
                  TAB-I (INDEXI + 1) = '2'  
                  MOVE '|' TO TAB-O (INDEXO)
                  ADD  2   TO INDEXI
                  ADD  1   TO INDEXO
                  PERFORM MOVE-CHAR THRU MOVE-CHAR-EXIT 
              ELSE  
              IF  TAB-I (INDEXI)     = '0' AND  
                  TAB-I (INDEXI + 1) = '3'  
                  MOVE '~' TO TAB-O (INDEXO)
                  ADD  2   TO INDEXI
                  ADD  1   TO INDEXO
                  PERFORM MOVE-CHAR THRU MOVE-CHAR-EXIT.
           PERFORM MOVE-CHAR THRU MOVE-CHAR-EXIT.   
           PERFORM MOVE-CHAR THRU MOVE-CHAR-EXIT.   
       FORMAT-CLE-EXIT. 
           EXIT.
       MOVE-CHAR.   
           MOVE TAB-I (INDEXI) TO TAB-O (INDEXO).   
           ADD  1 TO INDEXI.
           ADD  1 TO INDEXO.
       MOVE-CHAR-EXIT.
